# Booster Champion 3v3 仿真赛规则

> 来源：加速进化官网 + FAQ 文档，调研时间 2026-09-05

3v3 仿真足球锦标赛，面向全球开发者与具身智能爱好者。用 Booster Studio 组建机器人球队，全程 AI 自主运行。

## 二、比赛规则

### 基本设定
- **队伍**：每队 3 台人形机器人（1 门将 + 2 前锋/后卫）
- **运行方式**：全程完全自主 AI 运行，禁止人工遥控
- **场地**：小型标准足球场，四周有墙壁
- **用球**：橙色足球

### 积分规则
- 胜利：3 分
- 平局：各 1 分
- 失败：0 分
- 轮空（奇数队时）：3 分 + 3 粒净胜球

### 排名规则（优先级依次）
1. 积分（高者优先）
2. 胜场数（多者优先）
3. 净胜球（多者优先）
4. 总进球数（多者优先）
5. 犯规次数（少者优先）
6. 抽签

### 淘汰赛加时
- 淘汰赛阶段平局 → 金球制加时（最多 20 分钟）
- 加时内任一方进球 → 比赛立即结束，进球方胜
- 20 分钟仍平 → 线下抽签决定

## 三、判罚规则

### 自动裁判系统
Python 自动裁判，全部判罚由系统自动执行。

### 常见处罚

#### 机器人临时罚下（30 秒）
触发条件：
- 非法站位
- 定位球违规
- 阶段移动
- 倒地超时
- 长时间无活动（球在机器人 3m 范围内）

#### 罚时期间违规返场
- 重置剩余罚时 + 追加 1 次警告
- 累计 2 次警告 → 1 次黄牌（caution）
- 累计 2 次黄牌 → 红牌（sentOff），永久罚下

#### 定位球违例
- 防守方提前触碰皮球 / 未保持安全距离
- 重发本次定位球 + 违规机器人罚下 30 秒

#### 定位球超时
- 超时未开球 → 开放球权，双方均可触球

### 出界判定
- **标准**：整颗皮球完全越过场地界线才算出界，部分压线不算
- **边线球**：皮球越过边线 → 判界外球，球权归最后触球方的对手
- **底线球**：
  - 最后触球为进攻方 → 球门球
  - 最后触球为防守方 → 角球

### 乌龙球判定
- **定位球阶段**（界外球/球门球/角球）：防守方单次触球踢入己方球门 → 不计分，切换对方角球
- **运动战**：防守方自摆乌龙 → 进球有效，对方得分

### 开球规则
- 开球方对手必须离球至少 3 米
- 开球方队员在球未被其他队员触碰前不得再次触球
- 开球后、首次触球前进球，按球进门方向判定——进对方门有效得分；进己方门进球无效，判角球给开球方（位于开球方一侧底线）

## 四、代码提交规则

- 资格赛：每日 1 次挑战机会，可不限次更新代码
- 锁码时间：通常比赛日前 1 小时（以官方通知为准）
- 后续比赛：使用最近一次提交的代码，无需重新提交
- 比赛期间不允许修改代码/调整参数

## 五、技术合规

### Agent 架构（Booster 官方）
```
BoosterAgent 分层架构：
├── 感知层：球/敌方/球门识别（仿真赛提供真值坐标）
├── 定位层：坐标转换
├── 决策战术层：传球、射门、防守、多机协同
└── 运动执行层：步态控制
```

### 开发工具
- **Booster Studio**：一站式 IDE，内置仿真环境
- **BoosterAgent**：Python 开发框架
- **Booster Gym**：基于 NVIDIA Isaac Lab 的 RL 训练框架

### 通信
- 进程间通信 / ROS
- 支持 3 台机器人局域网协同

## 七、自由对战规则

- 随时向任意对手发起挑战
- 消耗"加速豆"（新用户注册赠送，邀请好友可获得）
- 每场挑战消耗 50 加速豆（无论胜负不退还）
- 可同时向多支队伍发起挑战
- 对战在云端仿真运行，无法实时观看
- 结束后可在"我的队伍 - 历史战绩"查看结果与回放
- 支持分享对战结果

### 对手选择
- **挑战强队**：系统精选（预选赛 Top 100 / 小组赛 32 强 / 淘汰赛按阶段展示）
- **指定对手**：模糊搜索队伍名称（仅能检索已提交代码的队伍）
- 不允许选择自身队伍

## 八、常见问题

### Q: 仿真赛代码能直接部署到真机吗？
A: 不能。3v3 仿真赛 Agent 依赖仿真环境真值坐标，省去视觉感知等环节，无法直接迁移。

### Q: 能使用自己的模型吗？
A: 平台提供官方示例模型，也支持自定义模型。但赛事 Agent 需同时管控 3 台机器人，自定义模型需自行适配。

### Q: 对战结果能实时观看吗？
A: 不能。对战在云端仿真，结束后查看回放。
